## Overview

This project investigates how **Unmanned Aerial Vehicle (UAV) footage can be used to analyse pedestrian movement patterns and changes in crowd density** through an integrated computer vision system.

Traditional fixed-camera monitoring can provide limited coverage of large outdoor spaces. UAV imagery offers a wider aerial perspective, but automatically interpreting crowd behaviour introduces challenges such as small pedestrian appearances, occlusion, tracking errors and changing viewpoints.

To explore these challenges, I developed a Python-based research prototype that combines:

- **Person detection** using a fine-tuned YOLO11s model.
- **Multi-object tracking** using ByteTrack.
- **Motion analysis** using pedestrian trajectories and displacement vectors.
- **Crowd-flow classification** into unidirectional, bidirectional and irregular movement.
- **Density-trend analysis** to identify increasing, stable and decreasing crowd counts.
- **Spatial density heatmaps** to visualise pedestrian concentration.
- **An interactive Streamlit application** for processing footage and exploring the generated results.

The project was developed as my MSc dissertation, *Analysis of Crowd Movement Patterns and Density Changes from UAV Videos*.

## Project Objectives

The main objective was to develop and evaluate an integrated application capable of extracting measurable crowd movement and density information from recorded UAV imagery.

The project focused on three technical questions:

1. How can pedestrian detection and multi-object tracking be combined to extract movement information from UAV footage?
2. How can individual trajectories be transformed into interpretable crowd-level movement and density characteristics?
3. How reliably can the resulting system classify crowd-flow patterns and density changes?

Rather than developing an isolated detection model, the emphasis was on **building and evaluating an end-to-end analytical pipeline**, including its user interface and downstream classification components.

## Application Showcase

### 1. Crowd Movement Analysis

![Crowd flow visualisation from the application](assets/crowd-flow.png)

The application uses tracked pedestrian positions to estimate movement vectors and analyse crowd behaviour over temporal windows.

Individual movement information is aggregated to identify the dominant direction and overall crowd-flow pattern.

Three flow categories are considered:

- **Unidirectional:** Predominantly aligned movement.
- **Bidirectional:** Two opposing movement directions.
- **Irregular:** Movement without a sufficiently consistent directional pattern.

The generated visualisation overlays representative movement arrows on the original UAV footage.

### 2. Spatial Density Heatmap

![Density heatmap generated by the application](assets/density-heatmap.png)

Spatial heatmaps illustrate where detected pedestrians are concentrated within the observed scene.

The system accumulates tracked pedestrian centre points within each analysis window, applies Gaussian smoothing and normalises the density representation by the number of frames.

The resulting heatmap is overlaid on the UAV imagery to make spatial concentration patterns easier to interpret.

This visualisation is distinct from density-trend classification: the **heatmap represents spatial concentration**, while the **density trend describes how the tracked-person count changes over time**.

### 3. Multi-Object Tracking

![Tracked pedestrians in a UAV frame](assets/multi-object-tracking.png)

The system combines YOLO11s detections with ByteTrack to associate pedestrians across consecutive frames.

Each active track is assigned a temporary identifier, allowing the application to construct movement trajectories and calculate displacement-based motion features.

The tracking output includes bounding boxes, track identifiers, pedestrian centre points and short trajectory trails.

Track identifiers are temporary and do not represent the real-world identities of individuals.

### 4. Interactive Web Application

![Interactive analysis dashboard](assets/dashboard.png)

A local web interface was developed using **Streamlit**, allowing users to explore the crowd-analysis pipeline without interacting directly with the underlying Python code.

The application supports:

- Selection of registered UAV frame sequences.
- Uploading an ordered sequence of images or a UAV video.
- Progress reporting during analysis.
- Previewing crowd-flow information and active tracking results.
- Reviewing generated tracking, crowd-flow and density videos.
- Inspecting analysis summaries and temporal-window information.
- Downloading structured analysis results.

The application processes footage locally rather than sending it to an external analysis service.

## System Architecture

The system follows a multi-stage computer vision pipeline:

**UAV footage → Person detection → Multi-object tracking → Motion extraction → Crowd-flow and density analysis → Visualisation and export**

| Stage | Implementation | Output |
|---|---|---|
| Input processing | Ordered image sequences or recorded UAV video | Individual video frames |
| Person detection | Fine-tuned YOLO11s | Pedestrian detections and confidence scores |
| Multi-object tracking | ByteTrack | Track IDs and pedestrian trajectories |
| Motion extraction | Bounding-box centre displacement | Motion magnitude and direction |
| Crowd-flow analysis | Temporal, rule-based analysis | Flow category and dominant direction |
| Density analysis | Tracked-person counts and spatial accumulation | Density trends and heatmaps |
| Visualisation | OpenCV and Streamlit | Annotated videos, dashboard summaries and CSV outputs |

### Person Detection and Model Selection

The person-detection component was developed through a series of model experiments.

An initial comparison considered **YOLOv8n, YOLO11n and RT-DETR-L**. A subsequent experiment compared YOLO11n and YOLO11s using a video-level training and validation split.

Both final YOLO11 models were trained using 1280 × 1280 images, with early stopping and validation-based model selection.

| Model | Validation precision | Validation recall | mAP50 | mAP50–95 |
|---|---:|---:|---:|---:|
| YOLO11n | 0.7553 | 0.6965 | 0.7479 | 0.3848 |
| **YOLO11s** | **0.7698** | **0.7444** | **0.7692** | **0.3968** |

**YOLO11s was selected** because it achieved stronger validation results across all four reported metrics.

The final pipeline used a detection confidence threshold of 0.40 and an IoU setting of 0.70.

### Multi-Object Tracking

ByteTrack was selected for its computational efficiency and integration with the detection pipeline.

Detections retained by YOLO11s are associated across consecutive frames to generate temporary pedestrian trajectories.

The implementation stores tracking information, including frame indices, confidence scores, bounding-box coordinates and centre points, in structured CSV outputs.

This separation allows subsequent movement analysis to use previously generated tracking results without rerunning person detection.

### Movement Feature Extraction

For each tracked pedestrian, the system calculates the displacement between bounding-box centre points in consecutive frames.

These displacements provide:

- Horizontal and vertical movement components.
- Movement magnitude in pixels per frame.
- Movement direction in degrees.
- Trajectory information across consecutive frames.

The movement features are aggregated over temporal windows to estimate dominant crowd direction, directional coherence and crowd-flow categories.

Because the footage was not calibrated to a real-world distance scale, the calculated motion values represent **pixel-space displacement**, not physical walking speed.

### Density-Trend Analysis

The density-trend component examines changes in the number of actively tracked pedestrians over time.

A temporal trend is estimated from the tracked-person counts and classified into three categories:

- **Increasing:** The active-person count shows a sufficiently positive trend.
- **Stable:** Changes remain within the defined tolerance.
- **Decreasing:** The active-person count shows a sufficiently negative trend.

The method provides an interpretable representation of relative crowd-count changes. However, its reliability depends on detection and tracking quality.

## Dataset

The project uses **DroneCrowd**, a UAV-based benchmark containing aerial image sequences and pedestrian annotations.

The experimental data was divided at video level:

| Dataset split | Videos | Images | Purpose |
|---|---:|---:|---|
| Training | 66 | 19,800 | Model development |
| Validation | 16 | 4,800 | Model selection |
| Test | 30 | 9,000 | Final evaluation |

The video-level split was used to reduce similarity leakage between training and validation footage.

The final system was evaluated on the **30 held-out test sequences**.

## Experimental Evaluation

The evaluation examined four main components independently:

1. Person detection.
2. Multi-object tracking.
3. Crowd-flow classification.
4. Density-trend classification.

Crowd-flow and density-trend classification were evaluated across **300 temporal windows**.

### Overall Results

| Component | Metric | Result |
|---|---|---:|
| Person detection | Precision | 0.727 |
| Person detection | Recall | 0.554 |
| Person detection | Point F1-score | 0.597 |
| Multi-object tracking | IDF1 | 0.560 |
| Multi-object tracking | Point-HOTA | 0.457 |
| Crowd-flow classification | Accuracy | 0.797 |
| Crowd-flow classification | Macro F1-score | 0.794 |
| Density-trend classification | Accuracy | 0.583 |
| Density-trend classification | Macro F1-score | 0.315 |

These results were obtained from the dissertation's final test evaluation and should not be confused with the earlier YOLO11 model-selection results.

### Crowd-Flow Classification

![Crowd flow classification confusion matrix](assets/flow-confusion-matrix.png)

Crowd-flow classification achieved **79.7% accuracy** and a **0.794 macro F1-score** across the evaluated temporal windows.

The results indicate that the extracted motion features can provide a useful representation of overall crowd-flow patterns under the tested conditions.

### Density-Trend Classification

![Density trend classification confusion matrix](assets/density-confusion-matrix.png)

Density-trend classification achieved **58.3% accuracy** and a **0.315 macro F1-score**.

This component proved more challenging, partly because missed detections, fragmented trajectories and fluctuations in tracked-person counts can affect the estimated trend.

The lower macro F1-score highlights the difficulty of reliably distinguishing increasing, stable and decreasing density trends using the implemented approach.

### Person Detection Performance

![Detection evaluation chart](assets/detection-performance.png)

The final detection evaluation was conducted across 30 test sequences.

Person detection achieved a precision of **0.727**, recall of **0.554** and Point F1-score of **0.597**.

Detecting pedestrians in UAV imagery is challenging because individuals can occupy very small image regions and may be partially occluded or difficult to distinguish from the background.

Detection performance is particularly important in this application because errors can propagate into tracking, crowd-flow analysis and density estimation.

## Engineering Considerations

The project involved several engineering decisions beyond model training:

**Modular processing:** Detection, tracking, movement analysis, density analysis and evaluation were organised into separate components.

**Structured outputs:** Tracking records and temporal analysis results were stored in CSV format to support inspection and further evaluation.

**Independent evaluation:** Detection, tracking and downstream classification were assessed using component-specific metrics rather than relying on a single overall accuracy value.

**Local processing:** The application was designed to process selected inputs locally through a Streamlit interface.

**Interpretability:** The system produces annotated footage, movement arrows, heatmaps and classification summaries so users can inspect the analytical outputs.

## Limitations and Future Work

This project is a **research prototype**, not a validated operational crowd-monitoring or public-safety system.

The main limitations include:

- **Detection sensitivity:** Small pedestrians, occlusion and challenging scene conditions can reduce detection accuracy.
- **Tracking reliability:** Missed detections and identity switches can interrupt pedestrian trajectories.
- **Error propagation:** Inaccurate tracking can affect both crowd-flow and density-trend predictions.
- **Camera movement:** The analysis assumes a sufficiently stable viewpoint and does not fully compensate for UAV camera motion.
- **Pixel-based measurements:** Movement magnitude cannot be interpreted as real-world speed without camera calibration.
- **Rule-based classification:** Flow and density categories depend on predefined temporal windows and decision thresholds.
- **Real-time capability:** Processing speed was not formally benchmarked for real-time deployment.
- **Generalisation:** Performance outside the evaluated DroneCrowd conditions has not been established.

Potential future improvements include more robust small-person detection, appearance-assisted tracking, camera-motion compensation, improved temporal density estimation and broader evaluation across UAV datasets.

Real-world deployment would also require appropriate privacy safeguards, human oversight and additional safety validation.
